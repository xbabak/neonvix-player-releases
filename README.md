# Neonvix IPTV Player Releases

This public repository hosts official Windows installers, electron-updater metadata, blockmaps, and required FFmpeg compliance archives and checksums.

Application source is maintained in a private repository and is not published here.

Download published versions from [Releases](https://github.com/xbabak/neonvix-player-releases/releases/latest). No release has been published yet.

For help, use the official Neonvix support channels.
